# VyUtils

VyUtils is a reusable Java utility library that provides common mathematical and string manipulation functions.

## Features

* Factorial Calculation
* Prime Number Checker
* Percentage Calculator
* Square Root Calculator
* Power Calculator
* String Reversal
* Palindrome Checker
* Character Counter

## Usage Example

```java
System.out.println(MathUtils.factorial(5));
System.out.println(StringUtils.reverse("Hello"));
```

## Requirements

* Java 17 or higher
